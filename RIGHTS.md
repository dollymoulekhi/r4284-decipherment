# Provenance, permissions and release status

Prepared 25 October 2026 for a preliminary article and code-only release.
The full historical evidence package is not included.

## Original contribution and credit

Dolly Moulekhi's study proposes applying R4325's horizontal alphabet strip to
the numerical letter in R4284. AI assisted analysis, coding and drafting.
The archive, database and cited researchers have not endorsed this result.

Riksarkivet holds the manuscripts. DECODE/DECRYPT provides access and research
infrastructure. Daniel Bourdeau's earlier R4284 transcription and research
notes informed the local investigation. They must not be presented as wholly
new work by this study.

## Withheld materials

The GitHub API reported `license: null` for `dbourdeau/cyphersolver` on
25 October 2026. Its repository root listing contained no license file; the
root README did not establish general redistribution permission in the
checks performed. This is a limited check, not a legal determination that
every item is protected or that permission cannot exist elsewhere.

A subsequent check of the [R4284 write-up](https://dbourdeau.github.io/cyphersolver/riksarkivet4284.html)
found a footer stating "Text released under CC BY 4.0" and separately crediting
manuscript rights to Riksarkivet via DECODE. The repository-wide API result
does not override that text license. Its applicability to the separate full
transcription files has not been established here.

The [DECODE terms](https://de-crypt.org/termsofuse.php) do not establish a
blanket image reuse license. This article therefore links to the opening
manuscript image hosted by Cyphersolver rather than copying or embedding it.
This is a precaution pending clarification, not a finding that reuse is prohibited.

No permission to redistribute inherited full transcriptions is asserted.
The full original/reviewed transcriptions, derived line ledger, complete
evidence archive, and scan binaries are therefore excluded from this site.
The full key data is also not included in this code-only download.

Public access is not the same as permission to copy and redistribute.
Rights may differ among manuscript content, modern transcriptions, images,
database content and code. Attribution alone does not resolve those questions.

## What is included

- An original explanatory article with short discussed reading excerpts,
  provisional English glosses, and one short numeric decoding example.
- A literal decoder and synthetic tests, without historic input files.
- Source links, references and explicit limitations.

The code-only ZIP is not a substitute for the withheld full reproduction
package. The local full package remains available only within this project.

No blanket license for the site, code, or third-party materials has been
selected. In particular, no license here grants rights in source scans or
inherited transcription data. Public availability does not grant a blanket
reuse license; permissions for the new material remain a separate decision.

No private correspondence, chat history, credentials, personal filesystem
paths, or office affiliations are intended for distribution.
