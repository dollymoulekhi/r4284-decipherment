# R4284: an independently checked archival-key match

Research in progress by Dolly Moulekhi. Updated 26 October 2026.

Read the article: https://dollymoulekhi.github.io/r4284-decipherment/

[Cyphersolver independent check and acceptance](https://github.com/dbourdeau/cyphersolver/issues/98#issuecomment-6406612222).
Daniel Bourdeau reports agreement with all 104 key assignments from an independent
image reading and accepts the match with credit to Dolly Moulekhi. The separate
statistical test is underdetermined (inconclusive), not a pass. The status remains
"decoded, not read"; the English interpretation is provisional, not independently
certified. This project review is not formal journal peer review.

The article documents a match between the numerical letter in DECODE R4284
and the horizontal alphabet strip in R4325. It reports a partial reading:
729/754 numeric occurrences receive alphabet assignments, not verified
plaintext accuracy. All 23 unmarked large groups remain unresolved.

The reader-facing article links to the original letter image, walks through
one numbers-to-letters example, and shows selected literal outputs alongside
editorial readings and provisional English glosses. It does not present a
complete translation or embed manuscript scans.

Open `index.html` in a browser to read the article. It uses local CSS only;
there is no analytics, external font, JavaScript or AI service dependency.

The `reproduction/` directory and code-only ZIP contain a standalone decoder
and synthetic tests. Full historical inputs are not included. See
`reproduction/README.md` and `RIGHTS.md` before using or redistributing anything.

The [public text-only evidence gist](https://gist.github.com/dollymoulekhi/a6eb279347dcbbf9c80aa0b0e23ca676)
separately supplies the full working key, both transcriptions, literal alignments,
scripts, and retrospective controls, with permission and attribution.
